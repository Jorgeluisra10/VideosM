PERFIL: MEDICINA · ARGENTINA (divulgación con dibujos anatómicos)

• Código de color ANATÓMICO obligatorio:
  – rojo = arterias, inflamación, dolor, bloqueo, peligro
  – azul = venas, receptores, membranas, flujo normal
  – amarillo = nervios, potencial de acción, ATP, enzimas, señales
  – hueso (blanco) = tejidos, huesos, estructura base, texto neutro
• Lateralidad: el brazo izquierdo del paciente (vista frontal) está a la DERECHA de la pantalla.
• Estructura: gancho → mecanismo (un paso por escena, causa → efecto) → remate. Escena 1 (gancho): la imagen más reconocible del tema + el «?» o el concepto que intriga. Última escena (remate): resume con un rotulo grande (≤ 2 rótulos, p. ej. «DOLOR» + «REFERIDO») y un gesto visual de cierre.
• Ayuda a recordar: la metáfora visual debe ser médicamente honesta (anatomía fiel en lo esencial; sin inventar estructuras ni datos). Rotula SIEMPRE las estructuras importantes con su nombre exacto.
• Para fórmulas usa O_{2}, H^{+}, Na^{+}.
• Cada escena trata UNA idea; una pieza anatómica principal por escena (máx. dos), centrada o ligeramente a un lado.
• Elementos recomendados: corazon, cerebro, cuerpo, columna, celula, membrana, neurona, grafica, pasos, comparacion, particulas, impulso, etiqueta, rotulo, dato.
• ÍCONOS PROFESIONALES: además de los dibujos propios, el elemento «icono» admite íconos «hi-*» de healthicons (hi-corazon, hi-pulmones, hi-rinones, hi-higado, hi-estomago, hi-neurologia, hi-nervio, hi-columna, hi-sangre, hi-globulos, hi-adn, hi-virus, hi-bacteria, hi-celula, hi-jeringa, hi-pildora, hi-estetoscopio…). Úsalos como acento o cuando el órgano no sea el protagonista (el protagonista va con corazon/cerebro/cuerpo/columna/celula/neurona). Color: hueso para estructura, rojo para dolor/bloqueo, amarillo para señal.
• RECORRIDOS QUE SE DIBUJAN SOLOS (evolvePath): usa «linea» (curva, con flecha o brillo) para mostrar el recorrido de un nervio o una señal, «vaso» para irrigación/flujo (rojo arteria, azul vena) y «impulso» para el potencial de acción viajando; en farmacología, «pasos» o «linea» con flecha para el mecanismo de acción (fármaco → receptor → efecto). Aparecen cuando la voz los nombra.
• Gráficos de datos (porcentaje de algo, curva): «grafica»; porcentajes simples: «forma» con forma «pastel».
